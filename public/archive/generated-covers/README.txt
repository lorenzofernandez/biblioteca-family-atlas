GENERATED COVER ARTWORK

Ten white-line-on-black ornamental assets created with the built-in image_gen tool, 18 October 2026. Exact prompts are in prompts.json.

The site composes a cover for each catalogue record with its own title, author, date and publication place. A shared style is selected from date and recorded geography. Records without sufficient metadata use the neutral frame; missing details are never invented. Early styles apply before 1800; nineteenth-century styles apply from 1800 through 1919; geometric styles apply from 1920. These broad visual interpretations are not reconstructions of original bindings.

Existing cover or reference images are displayed first. A failed image tries the next reference, then falls back to the generated design. Original catalogue scans remain unchanged.
